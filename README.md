# CALLSCENE

iPhone 수신 화면 스타일의 세로 이미지를 브라우저에서 만드는 정적 웹 편집기입니다.

## 주요 기능

- 실시간 9:19.5 미리보기
- 배경 이미지 업로드, 드래그, 확대 크롭
- 이름 및 상태바 시간 편집
- 한글/영문 UI 전환
- 슬라이드형/터치형 응답 화면 전환
- iOS 상태바 표시 및 배터리 수치 조절
- 1080 × 2340 고화질 PNG 저장
- 모든 이미지 처리는 사용자의 브라우저 안에서만 실행

## GitHub Pages 게시

1. 이 폴더 안의 파일을 새 GitHub 저장소의 최상위에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.

별도 설치나 빌드 과정은 필요하지 않습니다.

## 폰트

화면과 편집기에는 Apple SD Gothic Neo 폰트 파일을 사용합니다. 공개 배포 전 해당 폰트의 웹 배포 권한을 직접 확인하세요.
